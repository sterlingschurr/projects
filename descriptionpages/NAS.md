# Network Attached Storage and Container Application Server
Custom-built mini PC running Proxmox to handle file serving and containerized applications.

## The Problem
Subscriptions to cloud-based file storage like Google's Photos and Drive applications are very popular. While offering excellent convenience, these options constantly increase in cost and decrease in privacy every year. I desire the convenience of a dedicated file server without losing control over my own data, and without being at the mercy of someone else's pricing scheme.

## The Solution
![Concept diagram](media/NASconceptdiagram.jpg)
Using the power and flexibility of open-source software I plan to make a computer to solve this issue. Proxmox is known as a hypervisor, which allows multiple instances of an operating system to be loaded and running at the same time. Using these containerized instances, a robust network of computers can be simulated to run applications that serve the user's needs.

### Desired specifications
In particular, I needed it to accomplish these things:
- Automatic backup of photos from my phone
- Easy access to files from a windows computer
- A media consumption tool/environment for my movies and shows
- Access form outside my home network
