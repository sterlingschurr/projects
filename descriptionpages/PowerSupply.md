# Custom-Designed and Hand-Built AC-DC Power Supply
Constant voltage power supply made to spec using off-the-shelf components and hand soldering. 

## Class Project
This Project was completed as part of the ECEN350 class at BYUI. The Goal was to design and build an AC-DC constant voltage power supply based on principles we had learned throughout the class.
