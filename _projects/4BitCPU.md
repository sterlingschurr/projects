This is a 4-bit CPU built from the ground up using logic gates and hierarchical design.

## Class project
This was made as part of a class project at BYUI. It was created in the freely available ![Logisim software](https://github.com/logisim-evolution/logisim-evolution).

## The Solution
![Concept diagram](assets/images/4BitCPUconceptdiagram.jpg)
This project used hierarchical design. The plan was to begin by making simple structures such as adders, multiplexers, and decoders. Then using those more basic parts we would construct more complex ones like the ALU, up until we had an entire working CPU that could run our own machine code.
